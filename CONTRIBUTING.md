# Contributing to Permara

Thank you for your interest in Permara. We're building a decentralized protocol for verifiable payments, on-chain agreements, and funding.

## Our Position

Permara is focused on creating infrastructure where value can move with confidence. Our mission: **Trust endures. Value moves.**

We're currently in early development stages, laying the foundation for our protocol.

## Contributing

Since this repository is primarily for organization profile and community resources, your contributions can take these forms:

### Documentation

- Suggestions for improving our README, SECURITY policy, or this guide are welcome.
- We appreciate feedback on how we communicate our mission and values.

### Community

- Share what excites you about Permara's vision for verified payments and executable agreements.
- Spread the word through social channels:
  - [X / Twitter](https://x.com/permara_)
  - [Instagram](https://www.instagram.com/permara_com)
  - [LinkedIn](https://www.linkedin.com/company/permara-com)

### Code

- As we build out our protocol, we'll add repositories with open-source components.
- Code contributions will follow standard GitHub practices: fork, branch, and submit pull requests.

## Reporting Issues

- Open an issue for documentation suggestions or community feedback.
- For security concerns, see our [SECURITY.md](SECURITY.md) policy.

## Code of Conduct

We're building a community based on trust and transparency. Treat everyone with respect, and let's build something meaningful together.

## Status

> ⚠️ **Important**: Permara is under active development. Nothing on this page represents deployed, live, or production-ready services. We are not making claims about guaranteed security, regulatory approval, or live financial products.
